# Сканер карточек маркетплейса (расширение Chrome)

Собирает с открытой вкладки **URL**, **название**, **описание** (если есть), **цену** (JSON-LD / эвристики), **бренд**, **SKU**, **ссылки на фото** (через `;`) и время сбора. Данные копятся в `chrome.storage.local`, выгрузка — **Excel (.xlsx)**.

Поддерживаемые домены (whitelist): `wildberries.ru`, `ozon.ru`, `lamoda.ru`.

## Сборка

```bash
cd marketplace-scanner-extension
npm install
npm run build
```

Готовое расширение лежит в каталоге **`dist/`** (внутри должны быть `manifest.json`, `popup.html`, `popup.js`, `content.js`).

## Установка в Chrome / Edge

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → укажите папку `dist`.

После установки **перезагрузите** вкладку с товаром, затем нажмите иконку расширения → **Собрать с этой вкладки** → при необходимости **Экспорт в Excel**.

## Ограничения

- Вёрстка маркетплейсов меняется; приоритет у **JSON-LD `Product`** и **Open Graph**, затем лёгкие DOM-fallback для WB/Ozon.
- Массовый обход URL и обход авторизации **не входят** в этот MVP.
- Соблюдайте правила площадки и закон при использовании данных.
