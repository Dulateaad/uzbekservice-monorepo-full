# Решение проблемы SSH подключения

## Проблема
```
Connection closed by 95.46.96.53 port 22
```

Соединение устанавливается, но сразу закрывается. Это может быть из-за:

## Возможные причины и решения

### 1. SSH сервис не запущен на VPS

**Решение:** Нужно проверить через панель управления webspace.uz

### 2. Firewall блокирует SSH

**Решение:** Проверьте настройки firewall в панели управления

### 3. SSH настроен на другой порт

**Попробуйте:**
```bash
# Проверка других портов
ssh -p 2222 root@95.46.96.53
ssh -p 22022 root@95.46.96.53
```

### 4. Нужен другой пользователь

**Попробуйте:**
```bash
ssh admin@95.46.96.53
ssh ubuntu@95.46.96.53
ssh user@95.46.96.53
```

### 5. Использование панели управления

**Через webspace.uz:**
- Войдите в панель управления
- Найдите раздел "VPS" или "Серверы"
- Используйте **Web SSH** или **VNC консоль**
- Это даст доступ к серверу без SSH

### 6. Проверка доступности порта

```bash
# Проверка порта 22
nc -zv 95.46.96.53 22

# Или
telnet 95.46.96.53 22
```

### 7. Подробный вывод SSH

```bash
# Подключение с подробным выводом
ssh -v root@95.46.96.53

# Или еще более подробно
ssh -vvv root@95.46.96.53
```

## Рекомендуемые действия

### Шаг 1: Используйте панель управления webspace.uz

1. Войдите в личный кабинет webspace.uz
2. Найдите ваш VPS (gaysyrdl)
3. Используйте **Web SSH** или **VNC консоль**
4. Это даст прямой доступ к серверу

### Шаг 2: Через Web SSH выполните:

```bash
# Проверка SSH сервиса
systemctl status ssh
# или
systemctl status sshd

# Если не запущен, запустите:
systemctl start ssh
systemctl enable ssh

# Проверка firewall
ufw status
# Если активен, разрешите SSH:
ufw allow 22/tcp

# Проверка конфигурации SSH
cat /etc/ssh/sshd_config | grep -E "Port|PermitRootLogin"
```

### Шаг 3: Настройка SSH (если доступ есть)

```bash
# Редактируйте конфигурацию SSH
nano /etc/ssh/sshd_config

# Убедитесь, что есть:
# Port 22
# PermitRootLogin yes
# PasswordAuthentication yes

# Перезагрузите SSH
systemctl restart ssh
```

### Шаг 4: Альтернативные способы подключения

**Если SSH не работает, используйте:**

1. **Web SSH** в панели управления
2. **VNC консоль** для графического доступа
3. **KVM консоль** для полного доступа

## Проверка через панель управления

В панели управления webspace.uz должны быть:

- **Статус VPS** - проверьте, что сервер запущен
- **Сеть** - проверьте настройки firewall
- **SSH ключи** - возможно, нужно добавить ваш ключ
- **Консоль** - используйте Web SSH для доступа
