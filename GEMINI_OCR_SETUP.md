# Настройка AI для распознавания чеков (Business Hub)

## Проблема

При загрузке фото чека «ничего не происходит» — AI не настроен. Нужен **Gemini API ключ**.

## Решение

### 1. Получить API ключ

1. Откройте https://aistudio.google.com/apikey  
2. Войдите в Google-аккаунт  
3. Нажмите «Create API key»  
4. Скопируйте ключ (начинается с `AIza...`)

### 2. Добавить ключ для Web (PWA)

Откройте `web/index.html` и замените пустую строку:

```javascript
window.GEMINI_API_KEY = '';  // Замените на ваш API ключ
```

на:

```javascript
window.GEMINI_API_KEY = 'AIza...ваш_ключ...';
```

### 3. Добавить ключ при сборке (альтернатива)

```bash
flutter build web --release --dart-define=GEMINI_API_KEY=AIza...ваш_ключ...
```

## Что делает AI

- **Модель:** Gemini 1.5 Flash  
- **Вход:** фото чека/накладной (JPEG)  
- **Выход:** сумма, дата, контрагент, категория  
- **Формат:** JSON

## Обратная связь в приложении

- Если ключ не настроен — показывается предупреждение и кнопка неактивна  
- Если распознавание не удалось — показывается сообщение об ошибке  
- Ошибки API логируются в консоль браузера (F12)
