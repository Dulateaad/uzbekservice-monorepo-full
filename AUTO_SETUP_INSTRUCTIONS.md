# Автоматическая настройка VPS - Одна команда!

## 🚀 Автоматическая настройка

Я создал скрипт, который автоматически настроит все на VPS!

### Выполните одну команду:

```bash
cd /Users/dulatea/uzbekservice_app
./auto_setup_vps.sh
```

## 📋 Что делает скрипт

Скрипт автоматически:

1. ✅ Проверяет подключение к VPS
2. ✅ Загружает все необходимые файлы
3. ✅ Устанавливает PostgreSQL
4. ✅ Создает БД и пользователя
5. ✅ Создает таблицы
6. ✅ Устанавливает Node.js
7. ✅ Настраивает API сервер
8. ✅ Запускает API как systemd service
9. ✅ Настраивает firewall
10. ✅ Проверяет работу

## ⚠️ Требования

1. **SSH доступ к VPS** (пароль должен быть известен)
2. **VPS должен быть доступен** (ping работает)
3. **Вы должны быть в директории проекта**

## 🔐 Если SSH запрашивает пароль

Скрипт будет запрашивать пароль несколько раз:
- При загрузке файлов
- При выполнении команд на VPS

Введите пароль, который вы использовали для входа в VNC.

## 🆘 Если что-то пошло не так

### Проблема: SSH не работает

Используйте VNC и выполните команды вручную (см. `START_HYBRID_NOW.md`)

### Проблема: Ошибка при установке

Проверьте логи:
```bash
ssh root@95.46.96.53 "journalctl -u uzbekservice-api -n 50"
```

### Проблема: API не отвечает

Проверьте статус:
```bash
ssh root@95.46.96.53 "systemctl status uzbekservice-api"
```
