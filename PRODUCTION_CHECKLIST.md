## 📋 Быстрый старт для продакшена:

### Шаг 1: Резервное копирование (5 минут)

```bash
# Создать скрипт бэкапа
cat > /root/backup_db.sh <<'EOF'
#!/bin/bash
BACKUP_DIR="/root/backups"
mkdir -p $BACKUP_DIR
DATE=$(date +%Y%m%d_%H%M%S)
su - postgres -c "pg_dump uzbekservice_db" > $BACKUP_DIR/uzbekservice_db_$DATE.sql
# Удалить бэкапы старше 7 дней
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
EOF

chmod +x /root/backup_db.sh

# Добавить в cron (каждый день в 2:00)
echo "0 2 * * * /root/backup_db.sh" | crontab -
```

### Шаг 2: API ключ (10 минут)

Добавить простую проверку API ключа в `vps_api_server.js`:

```javascript
const API_KEY = process.env.API_KEY || 'CHANGE_THIS_SECRET_KEY';

// Middleware для проверки API ключа
app.use('/api', (req, res, next) => {
  const apiKey = req.headers['x-api-key'];
  if (apiKey !== API_KEY) {
    return res.status(401).json({ error: 'Unauthorized' });
  }
  next();
});
```

Обновить `.env`:
```
API_KEY=your_very_secure_random_key_here
```

Обновить `VpsApiService` в Flutter для отправки ключа.

### Шаг 3: HTTPS (30 минут)

Установить Nginx как reverse proxy с SSL:

```bash
dnf install -y nginx certbot python3-certbot-nginx
certbot --nginx -d api.yourdomain.com
```
