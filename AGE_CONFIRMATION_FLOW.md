# 🔄 Обновленный Flow подтверждения возраста и родительского согласия

## 📋 Изменения в логике:

### 1. Age Gate Screen (Экран проверки возраста)
**Было:** Ребенок выбирал дату рождения через календарь  
**Стало:** Ребенок вводит свой возраст (число) в текстовое поле

**Изменения:**
- Убрана дата рождения, добавлено поле ввода возраста
- Возраст сохраняется в `FirestoreAuthState.childAge`
- Валидация возраста (от 1 до 120 лет)
- Правильное склонение слова "год/года/лет"

### 2. Parental Consent Screen (Экран родительского согласия)
**Новая логика:**
1. Родитель вводит email и телефон
2. Родитель получает OTP код на email
3. После подтверждения OTP показывается возраст ребенка
4. Родитель должен:
   - ✅ Подтвердить возраст ребенка (чекбокс)
   - ✅ Принять на себя ответственность (чекбокс)
5. Только после этого можно подтвердить согласие

### 3. Модель ParentalConsent
**Добавлены поля:**
- `childAge` (int) - возраст ребенка, указанный ребенком
- `ageConfirmed` (bool) - подтвердил ли родитель возраст
- `responsibilityAccepted` (bool) - принял ли родитель ответственность

### 4. FirestoreAuthState
**Добавлено поле:**
- `childAge` (int?) - возраст ребенка, сохраняется после Age Gate

---

## 🔄 Полный Flow:

```
1. Ребенок вводит телефон → Beautiful Login Screen
2. Ребенок вводит имя (при регистрации) → Beautiful Login Screen
3. Ребенок вводит возраст → Age Gate Screen
   ↓
   Сохраняется в FirestoreAuthState.childAge
   ↓
4. Если возраст < 18 лет:
   → Переход к Parental Consent Screen
   ↓
5. Родитель вводит email → Parental Consent Screen
6. Родитель получает OTP на email → Email отправляется
7. Родитель вводит OTP → Проверка кода
8. После подтверждения OTP:
   → Показывается возраст ребенка
   → Родитель подтверждает возраст (чекбокс)
   → Родитель принимает ответственность (чекбокс)
   ↓
9. Родитель подтверждает согласие → Создается ParentalConsent в Firestore
   ↓
10. Отправляется SMS код ребенку → SMS Screen
11. Ребенок вводит SMS код → Завершение регистрации
```

## ✅ Преимущества новой логики:

1. **Проще для ребенка:** Не нужно помнить точную дату рождения, достаточно указать возраст
2. **Прозрачность для родителя:** Родитель видит возраст ребенка и подтверждает его
3. **Юридическая защита:** Родитель явно подтверждает возраст и принимает ответственность
4. **Соответствие требованиям:** Все данные логируются для соответствия COPPA и GDPR

## 🔍 Проверка работы:

1. ✅ Ребенок вводит возраст → Сохраняется в state
2. ✅ Родитель подтверждает OTP → Показывается возраст ребенка
3. ✅ Родитель подтверждает возраст → Сохраняется в согласии
4. ✅ Родитель принимает ответственность → Сохраняется в согласии
5. ✅ Согласие создается с полными данными → Сохраняется в Firestore
