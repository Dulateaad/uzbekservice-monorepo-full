# 🚀 Быстрый старт: Развертывание на VPS

## ✅ VPS готов к работе!

- **IP адрес:** 95.46.96.53
- **Домен:** webname.uz
- **Статус:** VPS доступен и отвечает на ping

## 📋 Шаг 1: Подключитесь к VPS

```bash
ssh root@95.46.96.53
```

При первом подключении подтвердите fingerprint (введите `yes`).

## 📋 Шаг 2: Настройте VPS (выполните на сервере)

После подключения к VPS выполните:

```bash
# Обновление системы
apt update && apt upgrade -y

# Установка Nginx
apt install nginx -y

# Установка Certbot для SSL
apt install certbot python3-certbot-nginx -y

# Создание директории для сайта
mkdir -p /var/www/webname.uz
chown -R www-data:www-data /var/www/webname.uz
```

## 📋 Шаг 3: Настройте Nginx

### Загрузите конфигурацию на VPS:

**С локального компьютера:**
```bash
cd /Users/dulatea/uzbekservice_app
scp vps_nginx_config.conf root@95.46.96.53:/etc/nginx/sites-available/webname.uz
```

**На VPS:**
```bash
# Активируйте конфигурацию
ln -s /etc/nginx/sites-available/webname.uz /etc/nginx/sites-enabled/
rm /etc/nginx/sites-enabled/default

# Проверьте конфигурацию
nginx -t

# Перезагрузите Nginx
systemctl reload nginx
```

## 📋 Шаг 4: Настройте DNS записи

В панели управления доменом **webname.uz** добавьте:

### A запись (основной домен):
```
Тип: A
Имя: @ (или пусто)
Значение: 95.46.96.53
TTL: 3600
```

### A запись (www):
```
Тип: A
Имя: www
Значение: 95.46.96.53
TTL: 3600
```

**Важно:** DNS записи могут распространяться до 24 часов.

## 📋 Шаг 5: Получите SSL сертификат

**На VPS:**
```bash
certbot --nginx -d webname.uz -d www.webname.uz
```

Следуйте инструкциям:
- Введите email для уведомлений
- Согласитесь с условиями
- Certbot автоматически настроит HTTPS

## 📋 Шаг 6: Задеплойте приложение

**С локального компьютера:**

```bash
cd /Users/dulatea/uzbekservice_app

# Автоматический деплой (рекомендуется)
./deploy_to_vps.sh
```

Скрипт автоматически:
- ✅ Соберет Flutter приложение
- ✅ Создаст бэкап на VPS
- ✅ Загрузит файлы
- ✅ Установит права доступа
- ✅ Перезагрузит Nginx

## 🆘 Проблемы?

### Не могу подключиться по SSH
```bash
# Проверьте доступность
ping 95.46.96.53

# Попробуйте подключиться
ssh root@95.46.96.53
```

### Домен не открывается
- Проверьте DNS записи (может занять до 24 часов)
- Проверьте, что Nginx запущен: `systemctl status nginx`
- Проверьте логи: `tail -f /var/log/nginx/error.log`

### SSL не работает
- Убедитесь, что порты 80 и 443 открыты
- Проверьте конфигурацию: `nginx -t`
- Проверьте сертификат: `certbot certificates`
