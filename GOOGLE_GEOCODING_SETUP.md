# Настройка Google Geocoding API

## ✅ Интеграция завершена

Google Geocoding API успешно интегрирован в приложение для автоматического получения координат по адресу.

## Как это работает

### 1. При регистрации специалиста

1. Специалист вводит адрес в поле "Адрес"
2. Нажимает кнопку "Получить координаты"
3. Система отправляет запрос к Google Geocoding API
4. Получает координаты (широта и долгота)
5. Автоматически обновляет адрес на форматированный из Google
6. Сохраняет координаты в профиле специалиста

### 2. На карте "Найти рядом"

- Все специалисты с указанным адресом отображаются на карте
- Маркеры показывают местоположение каждого специалиста
- Пользователь видит свое местоположение и специалистов рядом

## API Ключ

Текущий API ключ используется тот же, что и для Google Maps:
- Получается автоматически из `GoogleMapsService.getGoogleMapsApiKey()`
- Fallback: `AIzaSyAa8kAiaItTeaf2UTE1T2fDxV_Z57z7cjk`

## Настройка API ключа

### Вариант 1: Использовать существующий ключ (текущий)

Ключ уже настроен и работает автоматически.

### Вариант 2: Установить новый ключ программно

```dart
import 'package:odo_uz_app/services/geocoding_service.dart';

// Установить API ключ
GeocodingService.setApiKey('YOUR_API_KEY_HERE');
```

### Вариант 3: Через Environment Variables

При сборке приложения:
```bash
flutter build web --release \
  --dart-define=GOOGLE_GEOCODING_API_KEY=YOUR_API_KEY
```

## Получение API ключа Google Geocoding

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Выберите проект (или создайте новый)
3. Перейдите в **APIs & Services** → **Library**
4. Найдите **Geocoding API**
5. Нажмите **Enable**
6. Перейдите в **APIs & Services** → **Credentials**
7. Создайте **API Key** (или используйте существующий)
8. Ограничьте ключ:
   - **Application restrictions**: HTTP referrers (для веб)
   - **API restrictions**: Geocoding API, Maps JavaScript API

## Ограничения и квоты

### Бесплатный тариф:
- **$200 кредитов в месяц** (эквивалент ~40,000 запросов)
- После превышения: $5 за 1000 запросов

### Рекомендации:
- Кэшируйте результаты геокодирования
- Используйте один запрос на адрес
- Ограничьте API ключ по домену

## Примеры использования

### Геокодирование адреса

```dart
import 'package:odo_uz_app/services/geocoding_service.dart';

// Получить координаты по адресу
final coordinates = await GeocodingService.geocodeAddress(
  'ул. Амира Темура, 15, Ташкент, Узбекистан'
);

if (coordinates != null) {
  print('Широта: ${coordinates['lat']}');
  print('Долгота: ${coordinates['lng']}');
  print('Адрес: ${coordinates['formatted_address']}');
}
```

### Обратное геокодирование (координаты → адрес)

```dart
// Получить адрес по координатам
final address = await GeocodingService.reverseGeocode(
  41.2995, // lat
  69.2401  // lng
);

if (address != null) {
  print('Адрес: $address');
}
```

## Обработка ошибок

Сервис автоматически обрабатывает следующие ошибки:

- **ZERO_RESULTS**: Адрес не найден
- **OVER_QUERY_LIMIT**: Превышен лимит запросов
- **REQUEST_DENIED**: Запрос отклонен (проверьте API ключ)
- **INVALID_REQUEST**: Неверный запрос

Все ошибки логируются в консоль.

## Безопасность

⚠️ **ВАЖНО:**
- API ключ виден в клиентском коде (для веб)
- Ограничьте ключ по домену в Google Cloud Console
- Используйте серверный прокси для production (рекомендуется)
- Не храните секретные ключи в клиентском коде
