```bash

```

### Вариант 2: Через curl

```bash
curl -X POST https://us-central1-anama-app.cloudfunctions.net/sendParentalConsentOtp \
  -H "Content-Type: application/json" \
  -d '{
    "email": "ваш_email@example.com",
```
