## 🔄 Вход в правильный аккаунт:

### Шаг 1: Войдите в Firebase
```bash
firebase login
```

Откроется браузер для авторизации. Войдите в **правильный** аккаунт Firebase.

### Шаг 2: Проверьте список проектов
```bash
firebase projects:list
```

Убедитесь, что видите нужный проект.

### Шаг 3: Выберите правильный проект
```bash
firebase use odo-uz-app
```

Или если проект называется по-другому:
```bash
firebase use ПРАВИЛЬНОЕ_НАЗВАНИЕ_ПРОЕКТА
```

### Шаг 4: Проверьте текущий проект
```bash
firebase projects:list
```

Должен показать `odo-uz-app (current)` или ваш проект.

---

## 📋 Текущая конфигурация:

**Файл `.firebaserc`:**
```json
{
  "projects": {
    "default": "odo-uz-app"
  }
}
```

Если проект называется по-другому, обновите этот файл.

---

## 🔍 Проверка после входа:

### Проверить функции:
```bash
firebase functions:list
```

### Проверить хостинг:
```bash
firebase hosting:sites:list
```

### Проверить конфигурацию:
```bash
firebase functions:config:get
```
