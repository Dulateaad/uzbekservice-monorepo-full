### Возможные ошибки:

#### "This API key is not authorized"
**Решение**: Добавьте домен в ограничения API ключа в Google Cloud Console

#### "RefererNotAllowedMapError"
**Решение**: Проверьте, что домен добавлен в список разрешенных

#### "Google Maps JavaScript API error"
**Решение**: 
- Проверьте, что Maps JavaScript API включен
- Проверьте квоты API
- Проверьте, что ключ активен
