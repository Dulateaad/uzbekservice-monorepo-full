# Промпты для Gemini — перегенерация карточек Verdict

Формат карточки: `optionA` vs `optionB`, категория `category`.

Категории: `popular`, `paradox`, `philosophy`, `absurd`, `fast`, `gaming`, `love`, `family`, `character`, `money`, `lifestyle`.

---

## Один промпт — сгенерировать все карточки

Скопируй в Gemini:

```
Сгенерируй 100 карточек для приложения голосования "A vs B". 

Формат вывода — JSON массив, каждый элемент:
{ "optionA": "строка", "optionB": "строка", "category": "категория" }

Правила:
- optionA и optionB — короткие (1-3 слова), залипательные сравнения
- Категории: popular, paradox, philosophy, absurd, fast, gaming, love, family, character, money, lifestyle
- popular: звёзды, спорт, технологии, еда, путешествия
- paradox: неожиданные контрасты (Деньги vs Свобода)
- philosophy: глубокие жизненные вопросы
- absurd: смешные неожиданные пары
- fast: максимально простые (День vs Ночь)
- gaming: игры, фильмы, сериалы
- love, family, character, money, lifestyle: жизненные выборы

Выведи только валидный JSON, без markdown и пояснений.
```

---

## Промпт для каждой карточки (по одной)

Используй для перегенерации конкретной карточки. Подставь `OPTION_A`, `OPTION_B`, `CATEGORY`:

```
Придумай альтернативную формулировку для карточки голосования "A vs B". 
Исходная: OPTION_A vs OPTION_B, категория CATEGORY.
Верни только JSON: {"optionA": "...", "optionB": "...", "category": "CATEGORY"}
Варианты должны быть короткими (1-3 слова), залипательными, в том же духе.
```

## Промпт для локальных карточек (город/страна)

```
Сгенерируй 30 карточек A vs B для города [ГОРОД], страна [СТРАНА].
Локальные бренды, места, культура, менталитет.
Примеры: Kaspi vs Halyk (Казахстан), Алматы vs Астана.
Формат: JSON массив [{"optionA":"...","optionB":"...","category":"people"}]
Выведи только JSON.
```

Подставь: Алматы/Казахстан, Москва/Россия, Ташкент/Узбекистан и т.д.
