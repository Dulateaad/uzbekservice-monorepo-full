# ✅ Специалисты могут входить только через OneID

## 🔐 Что реализовано:

### 1. Проверка при отправке SMS кода ✅
В методе `_sendCode()` добавлена проверка:
- Если выбран тип пользователя "Специалист", происходит автоматический редирект на экран OneID входа
- SMS код не отправляется для специалистов

**Файл:** `lib/screens/auth/beautiful_login_screen.dart`
```dart
void _sendCode() async {
  if (!_formKey.currentState!.validate()) return;

  // ⚠️ СПЕЦИАЛИСТЫ МОГУТ ВХОДИТЬ ТОЛЬКО ЧЕРЕЗ OneID
  if (_selectedUserType == 'specialist') {
    context.go('/auth/specialist-oneid-login');
    return;
  }
  // ... остальной код для клиентов
}
```

### 2. Обновленный UI ✅
- При выборе "Специалист" скрываются поля для SMS входа
- Показывается информационное сообщение о необходимости входа через OneID
- Добавлена кнопка "Войти через OneID" для специалистов

### 3. Экран OneID входа ✅
- Экран `SpecialistOneIdLoginScreen` полностью реализован
- Маршрут `/auth/specialist-oneid-login` добавлен в роутинг
- Интеграция с Firebase Functions для OneID

---

## 📋 Как это работает:

### Для клиентов:
1. Выбирают "Клиент"
2. Видят форму с полями имени и телефона
3. Могут войти через SMS код

### Для специалистов:
1. Выбирают "Специалист"
2. Видят информационное сообщение:
   - "Специалисты могут войти только через OneID"
   - Описание OneID
   - Кнопка "Войти через OneID"
3. При нажатии на кнопку или попытке отправить SMS код → автоматический редирект на `/auth/specialist-oneid-login`
4. Могут войти только через OneID
