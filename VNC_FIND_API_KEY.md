# Как найти или сгенерировать API ключ

## 🔍 Проверка: Возможно ключ уже в .env

Выполните в VNC терминале:

```bash
cat /var/www/api/.env | grep API_KEY
```

Если ключ там есть - скопируйте его!

---

## 🔑 Если ключа нет - сгенерируйте заново

Выполните в VNC терминале:

```bash
# Генерируем новый ключ
API_KEY=$(openssl rand -hex 32)

# Показываем ключ
echo "=========================================="
echo "ВАШ API КЛЮЧ:"
echo "$API_KEY"
echo "=========================================="
echo ""
echo "⚠️  ВАЖНО: Скопируйте этот ключ и сохраните в безопасном месте!"
echo ""

# Добавляем в .env
echo "API_KEY=$API_KEY" >> /var/www/api/.env

# Проверяем
echo "✅ Ключ добавлен в .env:"
cat /var/www/api/.env | grep API_KEY
```

---

## 📋 После получения ключа

1. **Скопируйте ключ** - он понадобится для Flutter приложения
2. **Проверьте, что он в .env:**
   ```bash
   cat /var/www/api/.env
   ```
3. **Обновите Flutter приложение:**
   - Откройте `lib/services/vps_api_service.dart`
   - Найдите: `static const String _apiKey = 'YOUR_API_KEY_HERE';`
   - Замените `YOUR_API_KEY_HERE` на реальный ключ

---

## ✅ Готово!

После этого API будет защищен ключом.
