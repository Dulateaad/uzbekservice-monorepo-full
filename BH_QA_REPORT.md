# QA-отчёт: Business Hub — логика и флоу

## Общий флоу входа

1. **Услуги** → Business Hub → `BHMainScreen`
2. Если нет организации → дашборд показывает «Создать компанию» → `BHOnboardingScreen`
3. После создания → `context.go('/home/services/business-hub')` — возврат на главный экран BH

**Замечание:** При первом заходе в BH без организации пользователь видит призыв создать компанию. Флоу логичный.

## Исправленные баги (в этой сессии)

1. **Редактирование операции** — раньше создавался дубликат, теперь вызывается `updateOp`.
2. **Участники** — добавлена кнопка «Удалить» в PopupMenu.
3. **Владелец в members** — при создании org передаются `ownerName` и `ownerEmail`.
4. **Импорт при ошибках** — уточнён текст и отображение предупреждений.
5. **Выбор контрагента** — dropdown из списка + ручной ввод, сохраняется `counterpartyId`.
