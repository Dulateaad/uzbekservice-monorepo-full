# Инструкция по входу в VPS через VNC

## Текущая ситуация

Вы видите VNC консоль AlmaLinux с запросом логина:
```
gaysyrdl login: _
```

## Где найти учетные данные

### Вариант 1: Панель управления webspace.uz

1. Войдите в личный кабинет **webspace.uz**
2. Найдите ваш VPS: **gaysyrdl**
3. Откройте раздел **"Учетные данные"** или **"Пароли"**
4. Там должны быть:
   - **Логин** (обычно `root`)
   - **Пароль** (установленный при создании VPS)

### Вариант 2: Email от провайдера

Проверьте email, который вы получили при создании VPS:
- Тема: "Данные для доступа к VPS" или подобное
- Там должны быть логин и пароль

### Вариант 3: Сброс пароля в панели управления

Если пароль не найден:
1. Войдите в панель управления webspace.uz
2. Найдите ваш VPS
3. Используйте функцию **"Сброс пароля"** или **"Установить новый пароль"**
4. Установите новый пароль для root

## Что вводить

### Обычно для VPS:

**Логин:**
```
root
```

**Пароль:**
```
[Пароль из панели управления или email]
```

## Важные моменты

1. **Пароль не отображается** при вводе (это нормально)
2. **Регистр важен** - вводите точно как указано
3. **После ввода пароля нажмите Enter**

## После успешного входа

Вы увидите приглашение командной строки:
```
[root@gaysyrdl ~]#
```

Затем выполните настройку VPS (см. `START_HERE.md`):

```bash
# Обновление системы
apt update && apt upgrade -y

# Или для AlmaLinux (использует yum/dnf):
dnf update -y

# Установка Nginx
dnf install nginx -y

# Установка Certbot
dnf install certbot python3-certbot-nginx -y

# Создание директории
mkdir -p /var/www/webname.uz
chown -R nginx:nginx /var/www/webname.uz
```

## Если пароль не работает

1. **Проверьте Caps Lock** - пароль чувствителен к регистру
2. **Скопируйте пароль** из панели управления (без пробелов)
3. **Сбросьте пароль** через панель управления
4. **Обратитесь в поддержку** webspace.uz

## Альтернатива: Web SSH

Если VNC не работает, попробуйте **Web SSH** в панели управления:
- Обычно там те же учетные данные
- Более удобный интерфейс
