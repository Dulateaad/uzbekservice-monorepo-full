## 🎯 Описание продукта Anama

Приложение для мониторинга эмоционального состояния подростков:
- Ежедневный опросник для подростков
- Модуль мамы с ИИ-дашбордом (green/yellow/red)
- Push-уведомления маме при «красном» сигнале
- Интеграция с экстренными кнопками 111/150
- Запись к психологу
- ИИ-анализ через Gemini API
- Использование Firebase (Auth/Firestore/Cloud Functions)

## ⚠️ Критические зоны риска

### 1. Работа с несовершеннолетними
- Требуется согласие родителей

### 2. Чувствительная информация

### 3. ИИ-процессинг (Gemini API)
- Прозрачность передачи данных
- Минимизация и обезличивание информации
- Исключение идентификаторов

### 4. Публикация в Google Play и App Store
- Соответствие Kids/Families policies
- Запрет на идентификаторы устройства для детей
- Корректное раскрытие информации

### 5. Локализация в Казахстане
- Хранение данных на серверах в РК
- Соблюдение закона «О персональных данных и их защите»

## 📊 Карта данных (Data Map)

### Субъекты:
- **Подросток:** вводит ответы в «исповеди» (тексты/выборы)
- **Мама/родитель:** получает агрегированную аналитику (green/yellow/red)
- **Сторонние лица:** психологи, экстренные службы
- **Провайдеры:** Firebase, Google Gemini API

### Категории данных:
- Аккаунтные данные регистрации
- Контент подростка (ответы на вопросы)
- Аналитика/профиль риска (цветовой уровень)
- События кризиса (триггеры суицида)
- Технические/устройственные данные

### Потоки данных:
1. Подросток → Firebase Firestore (хранение)
2. Firebase/Cloud Functions → Gemini API (только текст и ID, без имён/телефонов)
3. Gemini → обратно (оценка/инсайты)
4. Система → push-уведомления маме при красном сигнале
5. Мама → запись к психологу

## 🔴 Красные флаги (требуют решения)

### 1. Возраст и «unknown age»
- Минимально допустимый возраст?
- Механизмы определения возраста
- Логика при невозможности определения возраста

### 2. Модель родительского согласия
- Методы подтверждения (email OTP, KYC-light, eGov)
- Сохранение истории согласий

### 3. Сырые тексты подростка
- Кто видит тексты? (команда проекта, психологи?)
- Как хранятся? (полный текст или только извлеченные отрывки?)

### 4. Crisis management
- Уведомляем ли родителя всегда?
- Что происходит при красном сигнале?
- Отказ от ответственности и инструкции

### 5. Локализация РК и Firebase
- Где физически хранятся данные?
- Процессы трансграничной передачи данных
