**Нужно создать:**
- Privacy Policy специально для Anama с учетом:
  - Работы с несовершеннолетними
  - Verifiable Parental Consent
  - ИИ-обработки через Gemini API
  - Разграничения доступа (родитель не видит сырые тексты)
  - Локализации данных в РК
  - Запрета на медицинские заключения

**Файлы:**
- `lib/screens/legal/anama_privacy_policy_screen.dart`
- `web/anama-privacy-policy.html`

### 3. Настроить отправку Email для OTP ⚠️
**Приоритет: ВЫСОКИЙ**

Сейчас OTP код выводится в консоль (для тестирования). Нужно настроить реальную отправку email.

**Варианты:**
1. Firebase Functions + SendGrid/Mailgun
2. Firebase Extensions (Email)
3. Собственный email сервис

**Что нужно:**
- Firebase Function для отправки email
- Интеграция с `parental_consent_service.dart`
- Шаблоны email писем

### 5. Обеспечить локализацию данных в РК ⚠️
**Приоритет: СРЕДНИЙ**

**Требуется:**
- Выбрать регион Firebase/Firestore в Азии (ближайший к РК)
- Настроить правила безопасности Firestore
- Документировать процесс трансграничной передачи данных

**Регионы Firebase:**
- `asia-south1` (Мумбаи) - ближайший к Казахстану
- `asia-east1` (Тайвань)
- `europe-west1` (Бельгия)
