# Решение проблемы подключения к VPS

## Проблема
```
ssh: Could not resolve hostname gaysyrdl.vps.webspace.uz: nodename nor servname provided, or not known
```

Это означает, что DNS имя VPS не разрешается. Нужно использовать IP адрес.

## Решение

### Вариант 1: Получить IP адрес из панели управления

1. Войдите в панель управления webspace.uz
2. Найдите информацию о вашем VPS
3. Скопируйте IP адрес

### Вариант 2: Использовать IP адрес напрямую

Если у вас есть IP адрес VPS, подключайтесь так:
```bash
ssh root@IP_АДРЕС_VPS
```

Например:
```bash
ssh root@123.45.67.89
```

### Вариант 3: Добавить в /etc/hosts (временное решение)

На macOS:
```bash
sudo nano /etc/hosts
```

Добавьте строку (замените IP на реальный):
```
123.45.67.89 gaysyrdl.vps.webspace.uz
```

Сохраните (Ctrl+O, Enter, Ctrl+X) и попробуйте снова:
```bash
ssh root@gaysyrdl.vps.webspace.uz
```

## Как узнать IP адрес VPS

### Способ 1: Из панели управления webspace.uz
- Войдите в личный кабинет
- Откройте информацию о VPS
- Найдите "IP адрес" или "IPv4"

### Способ 2: Через поддержку
- Напишите в поддержку webspace.uz
- Укажите название VPS: gaysyrdl
- Попросите предоставить IP адрес

### Способ 3: Если есть доступ к панели управления
- Обычно IP адрес отображается в информации о сервере
- Может быть в разделе "Серверы" или "VPS"

## После получения IP адреса

### 1. Подключитесь по IP:
```bash
ssh root@ВАШ_IP_АДРЕС
```

### 2. На VPS выполните команды:
```bash
# Узнать IP адрес (на Linux):
ip addr show
# или
hostname -I

# Узнать hostname:
hostname
```

### 3. Обновите скрипт деплоя

Отредактируйте `deploy_to_vps.sh`:
```bash
nano deploy_to_vps.sh
```

Измените строку:
```bash
VPS_HOST="ВАШ_IP_АДРЕС"  # Вместо gaysyrdl.vps.webspace.uz
```

Или используйте IP напрямую в командах:
```bash
# Вместо:
ssh root@gaysyrdl.vps.webspace.uz

# Используйте:
ssh root@ВАШ_IP_АДРЕС
```

## Альтернативный способ подключения

Если у вас есть доступ к панели управления webspace.uz, там может быть:
- **Web SSH** - терминал прямо в браузере
- **VNC консоль** - графический доступ
- **KVM консоль** - полный доступ к серверу

## Настройка SSH ключей (опционально)

Для удобства можно настроить SSH ключи:

```bash
# На локальном компьютере:
ssh-keygen -t rsa -b 4096

# Скопировать ключ на VPS:
ssh-copy-id root@ВАШ_IP_АДРЕС

# Теперь можно подключаться без пароля
ssh root@ВАШ_IP_АДРЕС
```

## Проверка подключения

После получения IP адреса проверьте:
```bash
# Ping для проверки доступности
ping -c 4 ВАШ_IP_АДРЕС

# SSH подключение
ssh root@ВАШ_IP_АДРЕС
```

## Следующие шаги

1. ✅ Получите IP адрес VPS
2. ✅ Подключитесь по IP: `ssh root@IP_АДРЕС`
3. ✅ Выполните настройку VPS (см. QUICK_VPS_SETUP.md)
4. ✅ Настройте DNS записи для webname.uz
5. ✅ Задеплойте приложение

## Важно

- **IP адрес** - это основной способ подключения к VPS
- **DNS имя** (gaysyrdl.vps.webspace.uz) может не работать, если DNS не настроен
- После настройки DNS для webname.uz, вы сможете использовать домен вместо IP
