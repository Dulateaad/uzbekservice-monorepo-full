# **App Name**: StyleAI

## Core Features:

- Product Upload: Admin interface to upload product details (name, description, price, images).
- Image Storage: Store the images uploaded through the admin panel into storage.
- AI Outfit Generation: Users upload their photo, and AI tool generates an image of the user wearing the selected clothing item.
- AI Styling Suggestions: AI suggests complementary items based on the selected clothing and user's uploaded photo.
- Product Display: Display products with images and descriptions.
- User Photo Upload: Allow users to upload a clear photo of themselves for virtual try-on.

## Style Guidelines:

- Primary color: Deep plum (#4A144B), evoking a sense of luxury and style.
- Background color: Light pink (#F8E8EE), a desaturated version of plum that is gentle and modern.
- Accent color: Warm coral (#FF7F50) for calls to action and highlights; provides a vibrant contrast to the plum.
- Body and headline font: 'Belleza', a humanist sans-serif to present a blend of personality and contemporary style.
- Minimalist icons related to clothing categories (shirts, pants, dresses, etc.)
- Clean and modern layout, easy navigation.
- Subtle transitions when the AI tool renders user photo with selected clothing.
