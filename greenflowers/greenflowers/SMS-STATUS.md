5. **Фронтенд готов** — создан компонент для тестирования

## ❌ Почему SMS не приходит

**Причина: SMSC.KZ счёт без денег (Error 3)**

Проверено форматами номероков:

- ✅ `77012345678` — правильный формат, но ошибка баланса
- ✅ `+77012345678` — принимается, но ошибка баланса
- ✅ Номера проходят валидацию, но SMSC отклоняет за недостаток средств

## 🔧 Как включить реальную отправку SMS

### Способ 1: Пополнить SMSC.KZ (рекомендуется)

1. Перейти: https://lk.smsc.kz
2. Учетные данные:
   - Login: `Sula_Bula`
   - Password: `Sul@2206`
3. Пополнить баланс минимум на 1000 тенге
4. SMS будут приходить автоматически

### Способ 2: Использовать для тестирования без реальных SMS

- Коды видны в DEV_MODE (API ответ)
- Можно полностью протестировать авторизацию
- Подходит для dev/staging окружения

## 🔑 Параметры в .env

```
SMSC_LOGIN=Sula_Bula
SMSC_PASSWORD=Sul@2206
DEV_MODE=true
```

DEV_MODE=true означает:

- Коды возвращаются в API ответе
- Можно локально тестировать без SMS
- В продакшене переставить на false
