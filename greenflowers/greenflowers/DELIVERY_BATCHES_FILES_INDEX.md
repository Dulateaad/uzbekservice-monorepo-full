## 🔧 Backend файлы

### Новые файлы

#### `back/routes/products-by-deliveries.js` ✅

**Размер:** ~350 строк  
**Назначение:** API endpoints для получения товаров, сгруппированных по поставкам

**Endpoints:**

```
GET /api/catalog/batches
  - Получить все партии с товарами
  - Параметры: limit, offset, sortBy, includeFresh
  - Response: { success, batches, total_count, today, pagination }

GET /api/catalog/batch/:id
  - Получить одну партию со всеми товарами
  - Response: { success, batch }

GET /api/catalog/today-deliveries
  - Получить только сегодняшние поставки
  - Response: { success, batches, count }
```

**Особенности:**

- Синхронизация с `inventory_batches` и `inventory_items`
- Расчет возраста партии (age_days)
- Определение статуса (is_new, is_fresh)
- Преобразование относительных URL в абсолютные
- Фильтрация товаров (only quantity > 0)
- Логирование всех операций

**Проверьте:**

```bash
curl http://localhost:5000/api/catalog/batches?limit=5
```

#### `sdfg/hooks/use-delivery-sync.ts` ✅

**Размер:** ~130 строк  
**Назначение:** Real-time синхронизация данных партий и товаров

**Функции:**

1. `useDeliverySyncWatch(batchId, onUpdate)`
   - Polling каждые 30 секунд
   - Проверяет изменилась ли партия
   - Вызывает callback при изменении

2. `DeliverySyncProvider`
   - Global listener для синхронизации
   - Провайдер для обертывания приложения

3. `notifyInventoryUpdate()`
   - Эмитирует событие "inventory:changed"
   - Вызывается после добавления/удаления товара

4. `useInventoryUpdates(callback)`
   - Hook для слушания обновлений инвентаря
   - Вызывает callback при изменении
