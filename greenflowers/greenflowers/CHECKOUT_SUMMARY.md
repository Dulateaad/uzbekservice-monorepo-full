## 🎯 Задача

Создать полноценный функционал оформления заказа для интернет-магазина Greenflowers с:

- Многошаговым интерфейсом
- Валидацией данных доставки

- Поддержкой гостей
- Очисткой корзины после заказа

## 🔄 Поток работы

```
1. Пользователь добавляет товары в корзину (add-to-cart)
2. Переходит в корзину (/cart)
3. Нажимает "Оформить заказ"
4. Если не авторизован → редирект на /auth/login
5. Если авторизован → редирект на /checkout
6. На странице /checkout:
   - Шаг 1: Просмотр сводки заказа
   - Шаг 2: Заполнение формы доставки
   - Шаг 3: Отправка заказа на API
   - Шаг 4: Показ сообщения об успехе
7. Корзина очищается
8. Пользователь может просмотреть заказ в /orders
```

1. Дата доставки устанавливается автоматически на +7 дней

3. Нет выбора города (берётся из CityContext)
4. Нет сохранения адресов
