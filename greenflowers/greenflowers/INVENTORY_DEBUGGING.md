# ✅ Диагностика: Позиции не отображаются

## Что нужно проверить:

### 1️⃣ Откройте DevTools (F12) в браузере

- Перейдите на вкладку **Console**
- Откройте страницу `/admin/inventory`
- Посмотрите логи (должны быть строки с 🚛 и 📦)

### 2️⃣ Ожидаемые логи:

```
🚛 Trucks API Response: {data: [...]}
🚛 Loaded trucks: X
🚛 Setting activeTruckId to: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
📦 Loading items for truck: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
📦 API Response: {success: true, data: [...]}
✅ Loaded items: 2
```

### 3️⃣ Если логов нет:

- Проверьте, что бэкенд запущен на port 5000
- Проверьте, что фронтенд запущен на port 3000
- Откройте Network tab в DevTools
- Посмотрите запросы к `/api/trucks` и `/api/inventory-items/truck/...`
- Проверьте, что ответы 200 OK

### 4️⃣ Если логи есть, но таблица пуста:

- Проверьте, что `items.length > 0` в консоли
- Посмотрите, что возвращает `response.data`
- Может быть, formData передается неправильно

### 5️⃣ Если позиции не появляются после добавления:

- Откройте Network tab
- Нажмите "Добавить позицию"
- Посмотрите POST запрос к `/api/inventory-items`
- Проверьте, что ответ `{success: true, data: {...}}`
- После ответа должны увидеть позицию в таблице

## Возможные проблемы:

### ❌ API Response неправильный

```javascript
// ❌ Неправильно:
{data: [...]}

// ✅ Правильно:
{success: true, data: [...]}
```

### ❌ ActiveTruckId не устанавливается

- Проверьте, что trucks загружаются
- Проверьте, что первый truck имеет `.id`

### ❌ Items не загружаются после выбора truck

- Проверьте, что activeT ruckId меняется
- Проверьте, что useEffect срабатывает

### ❌ Позиции добавляются, но не отображаются

- Проверьте Network tab при добавлении
- Посмотрите ответ API
- Проверьте, что `response.data.id` существует

## Рекомендации:

1. **Обновите страницу** (F5) после добавления позиции
2. **Проверьте консоль** - там будут все ошибки
3. **Посмотрите Network tab** - там видны все API запросы
4. **Выбирайте truck явно** - нажимайте на номер фуры в табах

---

**Если ничего не помогает:** Скопируйте логи из консоли и покажите.
