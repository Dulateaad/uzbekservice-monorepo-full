# 🌸 Greenflowers - Функционал оформления заказа

Полноценный функционал оформления заказа для интернет-магазина Greenflowers реализован!

## ✨ Что было реализовано

### 1. **Страница оформления заказа** (`/checkout`)

- Многошаговый интерфейс: Сводка → Форма доставки → Успех
- Загрузка данных пользователя из localStorage
- Интеграция с корзиной
- Отображение итоговой стоимости

### 2. **Компонент формы доставки** (`DeliveryForm`)

- Валидация всех полей
- Телефон: проверка формата регулярным выражением
- Город и адрес: обязательные поля
- Имя получателя: опциональное поле
- Отображение ошибок под каждым полем
- Состояние загрузки при отправке

### 3. **Компонент сводки заказа** (`OrderSummary`)

- Список товаров в корзине с ценами
- Расчёт итоговой стоимости
- Отображение способа оплаты
- Баннер успешного оформления (опциональный)
- Фиксированная позиция на странице (sticky)

### 4. **Поддержка гостевой корзины**

- Сохранение корзины в localStorage для неавторизованных пользователей
- Автоматическое преобразование между форматами
- Синхронизация при входе в аккаунт

### 5. **Интеграция с API**

- Создание заказа через POST `/api/orders`
- Корректный формат данных (snake_case)
- Обработка ошибок и ответов сервера
- Очистка корзины после успешного заказа

## 🚀 Как использовать

### Запуск Backend

```bash
cd back
npm install
npm start
```

Backend запустится на `http://localhost:5000`

### Запуск Frontend

```bash
cd sdfg
npm install
npm run dev
```

Frontend запустится на `http://localhost:3000`

### Процесс оформления заказа

1. **Добавить товары в корзину**
   - Откройте каталог товаров
   - Нажмите "Добавить в корзину"

2. **Перейти в корзину**
   - Нажмите иконку корзины в шапке
   - Или перейдите на `/cart`

3. **Начать оформление**
   - Нажмите кнопку "Оформить заказ"
   - Будет проверена авторизация
   - Если не авторизованы - редирект на login

4. **Сводка заказа** (Шаг 1)
   - Проверьте список товаров
   - Убедитесь в стоимости
   - Нажмите "Перейти к доставке"

5. **Форма доставки** (Шаг 2)
   - Введите адрес доставки
   - Выберите город
   - Введите номер телефона
   - Опционально: Введите имя получателя
   - Нажмите "Подтвердить и оформить"

6. **Успешное оформление** (Шаг 3)
   - Отобразится номер заказа
   - Будет показана информация о доставке
   - Кнопки для просмотра заказов или возврата на главную

## 🔧 API Интеграция

### Создание заказа

```typescript
POST /api/orders

Payload:
{
  user_id: number,
  customer_name: string,
  customer_phone: string,
  customer_email: string | null,
  total_amount: number,
  delivery_city: string,
  delivery_address: string,
  delivery_date: string (ISO),
  payment_method: "cash" | "kaspi_qr",
  payment_status: "pending" | "paid",
  notes: string | null,
  status: "pending" | "confirmed",
  items: Array<{
    product_id: number,
    quantity: number,
    unit_price: number
  }>
}

Response:
{
  success: true,
  message: "Заказ успешно создан",
  order: {
    id: number,
    user_id: number,
    total_amount: number,
    ... (другие поля)
  }
}
```

## ✅ Особенности и валидация

### Форма доставки

- **Адрес**: Обязателен, не пусто
- **Город**: Обязателен, не пусто
- **Телефон**: Обязателен, минимум 8 символов (цифры, пробелы, +, дефисы, скобки)
- **Имя**: Опционально

### Расчёт цен

- Приоритет: `price` → `price_per_box` → `price_per_unit * 50`
- Итого = сумма (цена_товара × кол-во)
- Доставка: Бесплатная
- Способ оплаты: Наличные при доставке

### Безопасность

- Проверка авторизации перед оформлением
- Валидация данных на frontend и backend
- Использование snake_case для API (стандарт Python/Django)

## 🔄 Поток данных

```
Cart (добавление товаров)
    ↓
Cart Page (просмотр, удаление, изменение кол-во)
    ↓
handleCheckout (проверка авторизации)
    ↓
/checkout страница (многошаговый интерфейс)
    ↓
DeliveryForm (ввод данных доставки)
    ↓
API создание заказа
    ↓
Успешное оформление + очистка корзины
    ↓
Перенаправление на /orders
```

## 🚨 Важные замечания

1. **Авторизация обязательна** - неавторизованные пользователи будут перенаправлены на `/auth/login`
2. **localStorage** - данные пользователя хранятся в `greenflowers_user`
3. **Гостевая корзина** - в `temp_cart` для неавторизованных пользователей
4. **Город** - используется из CityContext (выбирается в шапке)
5. **Дата доставки** - устанавливается на 7 дней вперёд автоматически
