## 🚀 Как использовать

### Создать новую фуру (Truck)

```
1. Перейти на /admin/inventory
2. Нажать "Добавить партию"
3. Заполнить данные:
   - Название фуры
   - Номер лицензии
   - Город доставки
   - ФИО водителя
   - Номер телефона
4. Нажать "Создать"
```

### Добавить позицию в фуру

```
1. Выбрать фуру в списке
2. Нажать "Добавить позицию"
3. Заполнить форму:
   - Название позиции (обязательно)
   - Количество (минимум 1)
   - Цена за единицу (обязательно)
   - Загрузить изображение (до 5МБ, опционально)
4. Нажать "Добавить"
```
