# 🎯 Чек-лист интеграции корзины и заказов

## ✅ Архитектура корзины

### Frontend

- [x] `CartContext` использует `user_id` из localStorage
- [x] При загрузке: если `userId` есть → загружает из БД, иначе → из `temp_cart`
- [x] Все операции (add, remove, update) содержат проверку userId
- [x] Гостевая корзина в localStorage временная (не синхронизируется)

### Backend

- [x] `GET /api/cart/user/:userId` — возвращает корзину только для этого userId
- [x] `POST /api/cart` — требует user_id в теле запроса
- [x] `PUT /api/cart/:itemId` — проверяет user_id перед обновлением
- [x] `DELETE /api/cart/:itemId` — проверяет user_id перед удалением
- [x] `DELETE /api/cart/user/:userId/clear` — очищает только корзину этого userId

### БД

- [x] Таблица `cart_items` имеет `FOREIGN KEY (user_id) REFERENCES users(id)`
- [x] Индекс на `user_id` для быстрого поиска
- [x] Constraint `UNIQUE(user_id, product_id)` предотвращает дубли

## 🆘 Возможные проблемы

### Проблема: "Корзина все ещё общая для всех"

**Решение**:

- Проверить, что `CartContext` загружает `userId` из localStorage
- Проверить, что `GET /api/cart/user/:userId` вызывается с правильным userId
- Очистить кэш браузера (Ctrl+Shift+Delete)

### Проблема: "Не вижу заказы в 'Мои заказы'"

**Решение**:

- Проверить, что используется `api.getUserOrders(user.id)`, а не `api.request("/orders", ...)`
- Проверить логи backend'а: `GET /api/orders/user/:userId`
- Убедиться, что заказ создался (проверить БД)

### Проблема: "Можно добавлять товары без авторизации"

**Решение**:

- Проверить, что в `Catalog.tsx` есть проверка `localStorage.greenflowers_user`
- Убедиться, что `CartContext` не позволяет добавлять товары при `userId === null`

### Проблема: "CORS ошибка"

**Решение**:

- Проверить, что backend включает CORS headers
- Проверить URL в api-client.ts (должен быть http://localhost:5000)
