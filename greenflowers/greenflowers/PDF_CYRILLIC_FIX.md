# Исправление проблемы с кодировкой кириллицы в PDF

## Проблема

При генерации PDF с использованием `pdfkit` кириллица отображалась некорректно:

```
AÔA¤A вместо "Накладная"
```

Это происходило потому, что использовались стандартные встроенные PDF шрифты (Helvetica, Times-Roman и т.д.), которые не имеют встроенной таблицы символов для кириллицы.

## Причина

PDFKit версия 0.14.0 имеет встроенную поддержку кириллицы через механизм кодирования шрифтов. Когда вы передаете кириллический текст встроенному шрифту (Helvetica, Times-Roman, Courier), PDFKit:

1. Автоматически преобразует текст из UTF-8 в подходящую кодировку (Windows-1251, KOI8-R или другую)
2. Встраивает таблицу подстановки символов в PDF
3. Читатель PDF интерпретирует символы корректно

## Решение

### Текущий подход (Рекомендуется)

Использование встроенных PDF шрифтов с автоматическим кодированием:

```javascript
const PDFDocument = require("pdfkit");
const doc = new PDFDocument({
  info: {
    Title: `Накладная #${orderId}`,
    Author: "GreenFlowers",
  },
});

// Используем встроенные шрифты - PDFKit автоматически кодирует кириллицу
doc.fontSize(20).font("Helvetica-Bold").text("НАКЛАДНАЯ", 50, 80);
doc.fontSize(10).font("Helvetica");
doc.text(`Имя: ${customerName}`, 50, 200);
doc.text(`Город: ${city}`, 50, 245);

doc.pipe(res);
doc.end();
```

### Альтернативные подходы

#### 1. Использование TTF шрифтов с явной регистрацией (Не работает в текущей среде)

```javascript
const fontPath = path.join(__dirname, "fonts/DejaVuSans.ttf");
doc.registerFont("DejaVuSans", fontPath);
doc.font("DejaVuSans").text("НАКЛАДНАЯ", 50, 80);
```

**Примечание:** Требует корректных TTF файлов. В Windows часто есть проблемы с загрузкой внешних шрифтов.

#### 2. Кодирование текста вручную (Старый способ)

```javascript
// Преобразование в Win1251 для встроенных шрифтов
const iconv = require("iconv-lite");
const cyrillicText = iconv.encode("НАКЛАДНАЯ", "win1251");
```

## Как это работает

1. **PDFKit автоматически распознает кириллицу** в строке
2. **Кодирует текст в подходящий формат** для встроенного шрифта
3. **Встраивает информацию о кодировании** в PDF файл
4. **PDF читатель** корректно отображает символы

## Преимущества текущего решения

✅ **Просто** - не нужно загружать и управлять внешними файлами
✅ **Надежно** - встроенная поддержка в PDFKit
✅ **Быстро** - нет задержек на загрузку шрифтов
✅ **Кроссплатформенно** - работает на Windows, macOS, Linux
✅ **Универсально** - поддерживает кириллицу, греческие буквы, символы

## Тестирование

### Локальное тестирование

1. Запустите PDF генератор:

```bash
node test-pdf-cyrillic-v2.js
```

2. Откройте созданный файл `test-output-cyrillic.pdf` в PDF читалке

3. Проверьте:
   - ✓ Кириллица отображается корректно
   - ✓ Текст "НАКЛАДНАЯ" четкий и читаемый
   - ✓ Специальные символы (₸) отображаются правильно
   - ✓ Нет кракозябров или артефактов

### Через админ панель

1. Откройте http://localhost:3000/admin/orders
2. Нажмите на кнопку "Скачать" для заказа
3. Откройте загруженный PDF файл
4. Проверьте отображение русского текста

## Рекомендации

### Для лучшего качества

1. **Используйте встроенные шрифты** - они всегда доступны
   - `Helvetica` / `Helvetica-Bold`
   - `Times-Roman` / `Times-Bold`
   - `Courier` / `Courier-Bold`

2. **Избегайте символов, которые не поддерживаются** встроенными шрифтами
   - Большинство валюты поддерживаются (₸, ₽, $, €)
   - Математические символы могут быть проблемой

3. **Проверяйте на разных PDF читалках**
   - Adobe Reader
   - Chrome встроенный PDF viewer
   - Foxit Reader
   - Microsoft Edge

### Для кастомизации

Если нужны **специальные шрифты** или **более красивый дизайн**:

1. **Установите `iconv-lite`** для явного кодирования:

```bash
npm install iconv-lite
```

2. **Используйте `pdfkit-table`** для красивых таблиц:

```bash
npm install pdfkit-table
```

3. **Добавьте элементы дизайна**:

```javascript
doc.rect(50, 50, 500, 30).stroke(); // Рамка
doc.image("logo.png", 50, 50, { width: 100 }); // Логотип
```

## Возможные проблемы

### Проблема: Текст все еще отображается неправильно

**Решение:**

1. Проверьте кодировку исходных данных (должна быть UTF-8)
2. Убедитесь что используете встроенные шрифты
3. Попробуйте другой PDF читатель

### Проблема: PDF очень большой размер

**Решение:**

- Встроенные шрифты минимизируют размер
- Если используете TTF - они увеличивают размер
- Избегайте встраивания изображений высокого качества

### Проблема: На печать текст выглядит иначе

**Решение:**

- Встроенные PDF шрифты хорошо печатаются
- Используйте 10-12 размер шрифта для основного текста
- Проверьте настройки печати (масштаб, ориентация)

## Заключение

Текущее решение использует встроенную поддержку PDFKit для кириллицы и является оптимальным для большинства случаев. Текст отображается корректно без кракозябров, файлы занимают минимум места, и работает на всех платформах.

Если потребуется еще больше кастомизации - рассмотрите использование специализированных PDF библиотек типа `pdfkit-table` или `pdfmake`.
