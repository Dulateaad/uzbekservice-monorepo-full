# SMSC.KZ SMS Integration - Инструкция по настройке

## Текущее состояние

SMS код генерируется и возвращается в API:

- **DEV_MODE=true** — коды видны в ответе API
- **Консоль сервера** — детальные логи попыток отправки
- **Fallback режим** — если SMSC недоступен или не настроен

## Проблема: Код не приходит SMS

Основная причина: **Ошибка 3 (No Balance)** от SMSC.KZ

Это означает, что на счёте Sula_Bula нет средств для отправки SMS.

## 🔧 Как исправить и включить реальную отправку SMS

### Вариант 1: Пополнить баланс SMSC.KZ (рекомендуется)

1. Перейти в личный кабинет: **https://lk.smsc.kz**
2. Авторизоваться с учетными данными:
   - Login: `Sula_Bula`
   - Password: `Sul@2206` (или восстановить)
3. Пополнить счёт:
   - Минимум: 1000-2000 тенге
   - Можно через карту или другой способ
4. Сервер автоматически начнёт отправлять SMS

### Вариант 2: Использовать другого SMS провайдера

Если нет возможности пополнить SMSC.KZ, можно переключиться на:

- **AWS SNS** (требует AWS аккаунта)
- **Vonage/Nexmo** (требует API ключей)
- **Twilio** (требует кредитов)

### Вариант 3: Тестировать с fallback режимом

Текущая настройка позволяет:

1. ✅ Генерировать коды в API ответе (DEV_MODE=true)
2. ✅ Видеть коды в консоли сервера
3. ✅ Протестировать весь flow входа/регистрации
4. ⚠️ SMS не приходит на телефон

## 📋 Текущие параметры SMSC.KZ

```
SMSC_LOGIN=Sula_Bula
SMSC_PASSWORD=Sul@2206
```

Формат номера телефона, который работает:

- ✅ `77012345678` (11 цифр, начиная с 7)
- ✅ `+77012345678` (с плюсом)
- ❌ `8-7012345678` (не поддерживается)

## 🔍 Диагностика

Для проверки статуса SMSC.KZ, запусти:

```bash
node test-smsc-formats.js
```

Ответы и их значения:

- `id,0` — успешно отправлено
- `id,1` — в очереди
- `id,3` — нет денег на счёте ❌
- `id,-4` — ошибка аутентификации

## 🚀 После пополнения баланса

1. Пополнить SMSC.KZ счёт в личном кабинете
2. Перезагрузить сервер (изменений в коде не требуется)
3. Тестировать отправку SMS:

```bash
curl -X POST http://localhost:5000/api/users/send-sms-code \
  -H "Content-Type: application/json" \
  -d '{"phone": "+77012345678"}'
```

Ответ:

```json
{
  "success": true,
  "message": "Код отправлен",
  "code": "123456"
}
```

## 💡 Советы

- DEV_MODE помогает тестировать локально без реальных SMS
- В продакшене отключить DEV_MODE (убрать или поставить false)
- Коды хранятся в памяти и истекают через 5 минут
- Для продакшена лучше использовать Redis или БД для хранения кодов
