# 👤 Страница профиля пользователя

## ✅ Реализовано

### 1️⃣ Отображение данных пользователя

- ✅ Имя пользователя
- ✅ Email (readonly поле)
- ✅ Адрес доставки (обязательное поле)
- ✅ Город (автоматически из Header, readonly)
- ✅ Номер телефона
- ✅ Роль пользователя с цветным бейджем

### 2️⃣ Автоматическое подтягивание города

- ✅ Город получается из `CityContext`
- ✅ При изменении города в Header - автоматически обновляется в профиле
- ✅ Поле города read-only (не редактируется)
- ✅ Информационное сообщение: "📌 Город берётся автоматически из выбранного в Header"

### 3️⃣ Редактирование профиля

- ✅ Кнопка "Редактировать" для включения режима редактирования
- ✅ При нажатии - поля становятся доступными
- ✅ Появляются кнопки "Сохранить" и "Отмена"
- ✅ При отмене - восстанавливаются исходные данные

### 4️⃣ Валидация данных

- ✅ Проверка обязательных полей:
  - Имя не может быть пустым
  - Адрес доставки не может быть пустым
- ✅ Если ошибка - показывается сообщение: "⚠️ Адрес доставки - обязательное поле"
- ✅ Сохранение запрещено при пустых обязательных полях
- ✅ Красное выделение поля при ошибке

### 5️⃣ Успешное сохранение

- ✅ Данные обновляются на бэкенде (PUT /users/profile)
- ✅ Данные обновляются в AuthContext
- ✅ Показывается успешное сообщение: "✅ Профиль успешно обновлен"
- ✅ Автоматический выход из режима редактирования

### 6️⃣ Система ролей пользователя

- ✅ Если `role === "admin"` → кнопка "Админ панель" (фиолетовая)
- ✅ Если `role === "worker"` → кнопка "Панель работника" (синяя)
- ✅ Обычные пользователи → не видят дополнительные кнопки
- ✅ Кнопки в отдельной секции "Админ-функции"

### 7️⃣ Современный интерфейс

- ✅ Карточка профиля по центру (max-w-2xl)
- ✅ Аватар с инициалом пользователя (зелёный градиент)
- ✅ Input поля с hover и focus эффектами
- ✅ Подсветка обязательных полей красной звёздочкой (\*)
- ✅ Город отображается в синем поле (readonly)
- ✅ Сообщения об ошибках с иконками
- ✅ Сообщения об успехе с иконками
- ✅ Кнопки с SVG иконками
- ✅ Адаптивная верстка (мобильная + десктоп)
- ✅ Красивые переходы и shadow эффекты
- ✅ Навигация в конце страницы (вернуться в каталог, мои заказы)

### 8️⃣ React логика

- ✅ `useState` для данных профиля (formData)
- ✅ `useState` для режима редактирования (isEditMode)
- ✅ `useState` для ошибок валидации (errors)
- ✅ `useEffect` для инициализации формы при загрузке пользователя
- ✅ Получение города из `useCity()` контекста
- ✅ Получение пользователя из `useAuth()` контекста
- ✅ Обновление пользователя через `updateUser()` из контекста

## 🚀 Использование

### Для пользователя

1. Войти в аккаунт
2. Нажать на кнопку "Профиль" в Header
3. Редактировать данные:
   - Нажать "Редактировать"
   - Заполнить поля (имя и адрес обязательны)
   - Нажать "Сохранить"
4. Город автоматически подтягивается из Header

### Для администратора/работника

- Дополнительные кнопки для переход в админ/работник панели

## 🔧 Установка

### Запуск миграции

```bash
cd back
node run-migration.js
```

Или вручную в БД:

```sql
ALTER TABLE users ADD COLUMN IF NOT EXISTS address TEXT;
```
