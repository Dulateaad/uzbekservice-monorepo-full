## 🔄 Архитектура потока данных

```
ГЛАВНАЯ СТРАНИЦА
  ┌─────────────────────┐
  │  ProductCard        │
  │  - Кнопка "+"       │
  └────────┬────────────┘
           │ onClick
           ▼
    useCart.addToCart()
           │
           ├─► API: POST /api/cart/add (если залогинен)
           └─► localStorage (если гость)
           │
           ▼
    CartContext.cart обновляется
           │
           ▼
    Header Badge обновляется (БЕЗ перезагрузки)

КОРЗИНА (/cart)
  ┌─────────────────────────────────┐
  │ Кнопка "Оформить заказ"         │
  └────────┬────────────────────────┘
           │
           ▼
  Проверка авторизации
           │
           ├─ НЕ залогинен → редирект на /auth/login
           └─ Залогинен → показать OrderModal
           │
           ▼
  OrderModal.handleSubmit()
           │
           ├─► API: POST /api/orders
           │   Body: {user_id, items[], total_amount, ...}
           │
           ▼
    Backend создает заказ в БД
           │
           ├─► INSERT into orders (user_id, ...)
           └─► INSERT into order_items (...)
           │
           ▼
    Frontend получает успех
           │
           ├─► clearCart()
           ├─► setCreatedOrderId()
           └─► Редирект на /order-confirmation/{id}

МОИ ЗАКАЗЫ (/orders)
  ┌────────────────────────────────────┐
  │ useEffect: loadOrders(user.id)     │
  │ API: GET /api/orders/user/:userId  │
  └────┬─────────────────────────────┬──┘
       │                             │
       ├─► setOrders(response.orders)
       │
       └─► useOrdersPolling() запускается
           │
           ├─ Первая проверка через 5 сек
           ├─ Дальше каждые 10 сек
           │
           ├─► Загружает обновленный список заказов
           ├─► Сравнивает statuses
           └─► Если изменилось → setOrders() БЕЗ перезагрузки

АДМИН-ПАНЕЛЬ (/admin/orders)
  ┌────────────────────────────────┐
  │ useEffect: loadOrders()         │
  │ API: GET /api/orders/all        │
  └────┬──────────────────────────┬─┘
       │                          │
       ├─► setOrders(response)
       │
       └─► useAdminOrdersPolling() запускается
           │
           ├─ Первая проверка через 5 сек
           ├─ Дальше каждые 15 сек
           │
           ├─► Загружает обновленный список всех заказов
           ├─► Сравнивает statuses
           └─► Если изменилось → setOrders() БЕЗ перезагрузки

ИЗМЕНЕНИЕ СТАТУСА (Admin Panel)
  ┌──────────────────────────────────┐
  │ handleStatusChange(orderId, newStatus)
  └────┬───────────────────────────┬──┘
       │                           │
       ├─► API: PUT /api/orders/{id}/status
       │   Body: {userId, status}
       │
       ▼
    Backend обновляет БД
       │
       ├─► UPDATE orders SET status = $1 WHERE id = $2
       │
       ▼
    Frontend обновляет state
       │
       ├─► setOrders() с новым статусом БЕЗ перезагрузки
       │
       ▼
    Выраженный на экране → БЕЗ ПЕРЕЗАГРУЗКИ

АВТОМАТИЧЕСКОЕ ОБНОВЛЕНИЕ У ПОЛЬЗОВАТЕЛЯ
    Polling в /orders компоненте
       │
       ├─ Каждые 10 сек: api.getUserOrders(userId)
       ├─ Сравнивает старый и новый status каждого заказа
       │
       ├─ Если отличается:
       │  └─► setOrders() с обновлёнными данными
       │
       ▼
    Пользователь ВИДИТ новый статус БЕЗ ПЕРЕЗАГРУЗКИ
```

## 📞 API Endpoints (использующиеся)

| Метод  | Endpoint                      | Функция                      |
| ------ | ----------------------------- | ---------------------------- |
| POST   | `/api/orders`                 | Создать заказ                |
| GET    | `/api/orders/user/:userId`    | Получить заказы пользователя |
| GET    | `/api/orders/all`             | Получить все заказы (admin)  |
| PUT    | `/api/orders/:orderId/status` | Изменить статус заказа       |
| DELETE | `/api/orders`                 | Удалить заказы               |
| POST   | `/api/cart/add`               | Добавить в корзину           |
| GET    | `/api/cart/user/:userId`      | Получить корзину             |
