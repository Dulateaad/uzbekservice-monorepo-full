# 🎨 Обновления интерфейса управления товарами

## ✨ Что изменилось:

### 1️⃣ Две кнопки вместо одной

**Было:**

```
[Добавить товар]
```

**Стало:**

```
[Создать товар] [Из каталога]
```

### 2️⃣ Кнопка "Создать товар" (зеленая)

- Открывает модальное окно для создания нового товара
- Вводишь название, количество, цену
- Можешь загрузить изображение
- Товар сохраняется в фуру

### 3️⃣ Кнопка "Из каталога" (синяя)

- Открывает каталог товаров
- Выбираешь товар из списка
- Нажимаешь "Добавить"
- Товар добавляется в фуру с количеством 1

### 4️⃣ Редактирование количества

- В таблице можешь нажать на поле "Кол-во"
- Изменить количество прямо в таблице
- Изменения автоматически сохраняются

### 5️⃣ Управление каталогом

- В модальном окне "Из каталога"
- Каждый товар имеет кнопку "Удалить"
- Можешь удалить товар из каталога полностью

## 📋 Как использовать:

### Создание нового товара:

```
1. Нажми "Создать товар"
2. Заполни форму:
   - Название товара
   - Количество
   - Цена за единицу
   - Загрузи фото (опционально)
3. Нажми "Создать"
```

### Добавление товара из каталога:

```
1. Нажми "Из каталога"
2. Выбери товар из списка
3. Нажми "Добавить" рядом с товаром
4. Товар добавится с количеством 1
```

### Изменение количества:

```
1. В таблице найди товар
2. Нажми на поле "Кол-во"
3. Вводи новое количество
4. Нажми Enter или кликни вне поля
5. Изменение сохранится автоматически
```

## 🎯 Основные изменения в коде:

### Новый компонент:

- `ProductCatalogModal.tsx` - модальное окно каталога товаров

### Обновленные компоненты:

- `InventoryTable.tsx` - добавлено редактирование количества
- `page.tsx` - две кнопки вместо одной + две модали

### Новые функции:

- `handleUpdateQuantity()` - обновление количества товара
- `handleSelectProductFromCatalog()` - добавление товара из каталога
- `updateInventoryItem()` в API - PUT запрос для обновления
