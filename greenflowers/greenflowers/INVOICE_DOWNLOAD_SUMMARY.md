# 📄 КРАТКИЙ ИТОГ: Скачивание PDF Накладной

## ✅ Что реализовано

На странице админ-панели `/admin/orders` каждый заказ теперь имеет кнопку **"Скачать"**, при нажатии на которую:

1. ✅ Отправляется GET запрос на backend: `GET /api/orders/:id/invoice?userId=1`
2. ✅ Backend генерирует PDF накладную из данных заказа
3. ✅ PDF автоматически скачивается на компьютер с названием `invoice_56.pdf`

## 🧪 Как протестировать

1. **Открыть админ-панель:**

   ```
   http://localhost:3000/admin/orders
   ```

2. **Нажать кнопку "Скачать"** у любого заказа

3. **Проверить:**
   - ✅ Консоль браузера (F12):
     ```
     [Download Invoice] Starting download for order 56
     [Download Invoice] Success
     ```
   - ✅ Файл скачался: `invoice_56.pdf`
   - ✅ PDF открывается и содержит корректные данные

## 🔧 Технические детали

| Компонент     | Технология                    |
| ------------- | ----------------------------- |
| PDF Генерация | pdfkit (Node.js)              |
| Скачивание    | fetch API + blob              |
| Авторизация   | Check role (admin/worker)     |
| SQL Запрос    | LEFT JOIN order_items         |
| Headers       | Content-Type: application/pdf |
