## 📊 Данные в системе

### Где хранятся партии?

Таблица `inventory_batches`:

```sql
id         | 1, 2, 3, ...
batch_date | 2026-02-22, 2026-02-19, ...
status     | 'received', 'draft', ...
supplier   | "Поставщик №1", ...
```

### Где хранятся товары в партиях?

Таблица `inventory_items`:

```sql
batch_id      | 1, 1, 1, 2, 2, ...
product_name  | "Роза", "Тюльпан", ...
quantity      | 50, 80, 150, ...
selling_price | 120, 90, 50, ...
```

**Как это работает:**

```
inventory_batches (партии)
    ↓ (один ко многим)
inventory_items (товары в партиях)
```

## 🔄 Синхронизация

### Как работает?

```
Работник добавляет товар на складе (TruckTabs)
         ↓
Сохраняется в БД (inventory_items)
         ↓
notifyInventoryUpdate() эмитирует событие
         ↓
Фронтенд слушает "inventory:changed"
         ↓
Перезагружает данные через API
         ↓
Новый товар видно на главной странице
```

### Интервал синхронизации?

- **Polling:** каждые 30 секунд проверяем изменилась ли партия
- **Event-based:** немедленно при явном обновлении (notifyInventoryUpdate)

Можно изменить в `use-delivery-sync.ts` переменная `30000` (миллисекунды)

## 🎨 Визуальные индикаторы

### Статус партии

| Статус    | Возраст  | Цвет       | Что это значит                                   |
| --------- | -------- | ---------- | ------------------------------------------------ |
| 🆕 Новое  | 0-1 день | 🟢 зеленый | Пришло сегодня/вчера, цветы в отличном состоянии |
| ✨ Свежее | 2-3 дня  | 🔵 синий   | Поступило недавно, можно предложить со скидкой   |
| 🔄 Старое | >3 дней  | ⚪ серый   | Старая партия, срочно распродать со скидкой      |

## 📈 Примеры использования

### Клиент на сайте

```
1. Открывает главную
2. Видит "🆕 НОВОЕ - поставка 22.02.26"
3. Знает что цветы свежие
4. Кликает "Дальше →" чтобы看 старые партии
5. По поводу старых видит "🔄" - может быть скидка
6. Выбирает партию и добавляет в корзину
```

### Менеджер на складе

```
1. Заходит на TruckTabs (управление складом)
2. Добавляет новый товар в партию
3. Сохраняет
4. notifyInventoryUpdate() уведомляет фронтенд
5. На главной странице товар появляется через 30 сек
   (или немедленно if he's watching)
```
