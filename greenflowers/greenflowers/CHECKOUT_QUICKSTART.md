# 🚀 Быстрый старт

## За 5 минут до запуска

### 1️⃣ Запустить Backend

```bash
cd back
npm start
```

Должно вывести: `✅ Database connected successfully`

### 2️⃣ Запустить Frontend

```bash
cd sdfg
npm run dev
```

Должно вывести: `▲ Next.js ready on http://localhost:3000`

### 3️⃣ Открыть браузер

```
http://localhost:3000
```

## 🧪 Тестирование функционала

### Сценарий 1: Авторизованный пользователь

```
1. Зайти на главную (http://localhost:3000)
2. Авторизоваться (Sign Up / Log In)
3. Перейти в каталог (Catalog)
4. Добавить товар в корзину (нажать "Добавить в корзину")
5. Открыть корзину (иконка в шапке)
6. Нажать "Оформить заказ"
   → Должна открыться страница /checkout
7. На странице сводки:
   - Проверить список товаров
   - Проверить итоговую сумму
   - Нажать "Перейти к доставке →"
8. На странице формы:
   - Заполнить адрес (например: "ул. Примерная, 123")
   - Заполнить город (например: "Almaty")
   - Заполнить телефон (например: "+7 (999) 123-45-67")
   - Опционально: Заполнить имя (например: "Иван Петров")
   - Нажать "Подтвердить и оформить →"
9. Ждать обработки (появится загрузочный спиннер)
10. На странице успеха:
    - Должно быть сообщение "Ваш заказ успешно оформлен!"
    - Должен быть номер заказа (например: #44)
    - Нажать "Мои заказы"
    - Проверить, что заказ появился в списке

✅ Сценарий успешен!
```

### Сценарий 2: Гостевой пользователь

```
1. Зайти на главную (http://localhost:3000)
2. НЕ авторизоваться
3. Перейти в каталог (Catalog)
4. Добавить товар в корзину
5. Открыть корзину
6. Нажать "Оформить заказ"
   → Должно быть перенаправление на /auth/login
   → Показано сообщение "Пожалуйста, войдите в аккаунт"

✅ Редирект работает правильно!
```

### Сценарий 3: Валидация формы

```
1. До конца пройти до шага 2 (форма доставки)
2. Попробовать отправить пустую форму
   → Должны быть ошибки:
     "Адрес доставки обязателен"
     "Город обязателен"
     "Телефон обязателен"
3. Заполнить неправильный телефон (например: "123")
   → Должна быть ошибка: "Неверный формат телефона"
4. Заполнить правильный телефон (+7-999-1234567)
   → Ошибка исчезает
5. Заполнить остальные поля
6. Нажать "Подтвердить и оформить →"
   → Заказ должен быть создан

✅ Валидация работает!
```

## 📝 Типичные ошибки

### ❌ "Пожалуйста, войдите в аккаунт"

**Решение**: Авторизуйтесь сначала или используйте Sign Up

### ❌ "API недоступна"

**Решение**: Убедитесь, что `cd back && npm start` выполнена

### ❌ Форма не отправляется

**Решение**: Проверьте:

- Все ли поля заполнены?
- Телефон в правильном формате?
- Нет ли ошибок в console?

### ❌ Корзина пуста

**Решение**: Сначала добавьте товары в каталоге
