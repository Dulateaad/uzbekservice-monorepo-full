## 🔍 Быстрая проверка (все ✅ = система работает)

### 1️⃣ Фронтенд загружается

- [ ] `http://localhost:3001` открывается без ошибок
- [ ] Header видна, товары загружены
- [ ] В header видна иконка корзины

### 2️⃣ Добавление в корзину

- [ ] На главной странице видна кнопка "+" на товарах
- [ ] При клике "+" появляется уведомление "Товар добавлен в корзину"
- [ ] Badge в header показывает количество (красный кружок с числом)
- [ ] При клике на несколько товаров число увеличивается

### 3️⃣ Страница корзины

- [ ] Можно перейти в корзину (иконка в header или `/cart`)
- [ ] Корзина показывает добавленные товары
- [ ] Есть кнопка "Оформить заказ"
- [ ] Если не залогинен - редирект на `/auth/login`

### 4️⃣ Оформление заказа

- [ ] Кликните "Оформить заказ"
- [ ] Появляется модальное окно "Оформить заказ?"
- [ ] Показывает сумму к оплате (в ₸)
- [ ] Есть кнопки "Отмена" и "Подтвердить"
- [ ] После подтверждения корзина пуста
- [ ] Заказ создан (можно увидеть в консоли: `[Order creation] API Response: {success: true}`)

### 5️⃣ Загрузка заказов пользователя

- [ ] Откройте `/orders` (или перейдите на "Мои заказы")
- [ ] Видна таблица с заказами
- [ ] Заказ, созданный в пункте 4, видна в списке
- [ ] Показан статус "Ожидание"
- [ ] Показана сумма и адрес доставки

### 6️⃣ Админ-панель заказов

- [ ] Откройте `/admin/orders`
- [ ] Видна таблица со ВСЕМИ заказами
- [ ] Заказ из пункта 4 видна в списке
- [ ] Есть кнопки для изменения статуса

### 7️⃣ Изменение статуса администератором

- [ ] В админ-панели найдите созданный заказ
- [ ] Нажмите на строку или кнопку "Статус"
- [ ] Выберите новый статус из dropdown (например, "Обработка")
- [ ] Нажмите "Применить"
- [ ] Статус в таблице обновляется БЕЗ перезагрузки страницы

### 8️⃣ Real-time обновление у пользователя (КЛЮЧЕВОЙ ТЕСТ!)

- [ ] Откройте второй браузер/вкладку на `/orders` (мои заказы)
- [ ] НЕ ПЕРЕЗАГРУЖАЙТЕ эту вкладку
- [ ] Вернитесь в админ-панель и измельте статус ещё раз (например, на "Отправлен")
- [ ] Вернитесь на вкладку с `/orders` пользователя
- [ ] **ГЛАВНОЕ:** Статус обновился АВТОМАТИЧЕСКИ БЕЗ перезагрузки страницы
- [ ] В консоли должны быть логи: `[OrdersPolling] Status changes detected, updating...`

## 🐛 Отладка (если что-то не работает)

### Заказ не добавляется/не видно в списке

```javascript
// Откройте консоль (F12) и проверьте:
1. localStorage.getItem('greenflowers_user') // должна быть дата пользователя
2. В Network (F12) → POST /api/orders → должен быть Status 201 или 200
3. В консоли должно быть: [Order creation] API Response: {success: true}
```

### Статус не обновляется у пользователя

```javascript
// Откройте консоль и проверьте логи:
[OrdersPolling] Status changes detected, updating...
// Если нет этого лога:
- Проверьте что user.id есть: console.log('user.id:', user?.id)
- Проверьте что orders не пуста: console.log('orders:', orders)
```

### Админ-панель не показывает заказы

```javascript
// В Network → GET /api/orders/all → должен быть Status 200
// Response должен содержать массив orders []
// Если пусто - проверьте что заказы действительно созданы в БД
```

## 🔧 Настройки polling (если нужно изменить)

**Файлы:**

- `sdfg/hooks/use-orders-polling.ts` - для пользователя
- `sdfg/hooks/use-admin-orders-polling.ts` - для админа

**Параметры:**

```typescript
useOrdersPolling(
  orders,
  setOrders,
  user?.id || null,
  true, // enabled - включить/отключить
  10000, // интервал в миллисекундах (10000 = 10 сек)
);
```

Если нужно изменить интервал:

- Пользователь: измените 10000 на, например, 5000 (5 сек)
- Админ: измените 15000 на нужное значение
