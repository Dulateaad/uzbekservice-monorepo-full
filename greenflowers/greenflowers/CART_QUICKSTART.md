## 🎯 Тестирование функционала

### ✅ Тест 1: Добавление товара в корзину

```
1. Откройте главную страницу
2. Найдите раздел "Каталог"
3. Нажмите кнопку "+" на любом товаре
4. Если не авторизованы → покажется уведомление "Войдите в аккаунт"
5. Авторизуйтесь (Sign Up / Log In)
6. Нажмите "+" снова
7. ✓ Товар должен добавиться в корзину
8. ✓ Badge в шапке обновится (покажет количество)
```

---

### ✅ Тест 2: Badge с количеством товаров

```
1. Добавьте несколько товаров в корзину (кнопка "+")
2. Смотрите на иконку 🛒 в шапке
3. ✓ Красный круг с количеством должен обновляться сразу
4. ✓ При добавлении товара число должно увеличиваться
5. ✓ Без перезагрузки страницы
```

---

### ✅ Тест 3: Страница корзины

```
1. Нажмите на иконку 🛒 в шапке (или перейдите на /cart)
2. ✓ Должен открыться список товаров в корзине
3. Попробуйте:
   - Увеличить/уменьшить количество товара
   - Удалить товар (красная кнопка "Удалить")
   - Очистить всю корзину
4. ✓ Цены и итого должны пересчитываться сразу
```

---

### ✅ Тест 4: Восстановление корзины после входа

```
1. Выйдите из аккаунта (если авторизованы)
2. Добавьте товар в корзину без авторизации
   → Покажется уведомление "Войдите в аккаунт"
   → Перенаправление на /auth/login
3. Зарегистрируйтесь/авторизуйтесь
4. ✓ Возможно, товары из временной корзины загрузятся
5. Перейдите на /cart
6. ✓ Корзина должна содержать ваши товары
```

---

### ✅ Тест 5: Оформление заказа

```
1. Добавьте товары в корзину
2. Перейдите на /cart
3. Нажмите "Оформить заказ"
4. Если не авторизованы → редирект на login
5. Если авторизованы → редирект на /checkout
6. Пройдите процесс оформления (заполните форму)
7. ✓ Заказ должен быть создан
8. ✓ Корзина должна очиститься
```

---

### ✅ Тест 6: Мои заказы

```
1. После оформления заказа нажмите "Мои заказы"
2. Перейдите на страницу /orders
3. ✓ Должны видеть список оформленных заказов
4. ✓ Каждый заказ должен содержать товары и сумму
```

## 🔍 Проверка в DevTools (F12)

### Console

Проверьте наличие логов:

```javascript
// При добавлении товара
[CartContext] Adding product: Rose Red, quantity: 1

// При удалении
[CartContext] Removing product: 1

// При обновлении количества
[CartContext] Updating quantity: item 1 → 5
```

### Network (XHR)

Проверьте запросы:

```
POST /api/cart/add        ← Добавление товара
DELETE /api/cart/item/:id ← Удаление товара
PUT /api/cart/item/:id    ← Обновление количества
DELETE /api/cart          ← Очистка корзины
POST /api/orders          ← Создание заказа
```

### Storage (localStorage)

```
greenflowers_user: {id, email, ...}  ← Данные пользователя
temp_cart: [{...}, {...}]            ← Временная корзина (для гостей)
```

## 🎓 Примеры кода

### Использование CartContext

```typescript
import { useCart } from "@/contexts/cart-context";

export function MyComponent() {
  const {
    cart,
    addToCart,
    removeFromCart,
    getCartCount,
    getCartTotal
  } = useCart();

  // Добавить товар
  const handleAdd = async () => {
    await addToCart(product, 1);
  };

  // Удалить товар
  const handleRemove = async (itemId) => {
    await removeFromCart(itemId);
  };

  return (
    <div>
      <p>Товаров: {getCartCount()}</p>
      <p>Итого: {getCartTotal()} KZT</p>
    </div>
  );
}
```
