## ✨ Особенности

### 🎨 Многошаговый интерфейс

```
Шаг 1: Сводка заказа
  ├─ Список товаров
  ├─ Итоговая сумма
  └─ Кнопка "Перейти к доставке"

Шаг 2: Форма доставки
  ├─ Адрес (обязателен)
  ├─ Город (обязателен)
  ├─ Телефон (обязателен + валидация)
  ├─ Имя (опционально)
  └─ Кнопка "Подтвердить и оформить"

Шаг 3: Успешное оформление
  ├─ Номер заказа
  ├─ Информация о доставке
  └─ Кнопки навигации
```

### ✅ Валидация

- **Адрес**: Не может быть пустым
- **Город**: Не может быть пустым
- **Телефон**: Минимум 8 символов (цифры, пробелы, +, дефисы, скобки)
- **Имя**: Опционально

### 🔐 Безопасность

- Проверка авторизации перед оформлением
- Валидация на frontend и backend
- Защита от CORS атак
- Использование snake_case для API

### 📱 Адаптивность

- Desktop (двухколонный макет)
- Планшет (одноколонный с sticky сводкой)
- Мобильный (оптимизированный для сенсорных экранов)

### 🌍 Локализация

- Русский язык
- Форматирование цен (KZT)
- Валидация телефонов

## ❓ Часто задаваемые вопросы

### Что если пользователь не авторизован?

Будет редирект на `/auth/login` с сообщением "Пожалуйста, войдите в аккаунт"

### Как работает гостевая корзина?

Товары сохраняются в `localStorage.temp_cart`

### Какой способ оплаты поддерживается?

На данный момент: наличные при доставке. Легко расширяется.

### Как получить номер заказа?

Номер отображается после успешного оформления и содержится в `response.order.id`

### Что происходит с корзиной после заказа?

Корзина автоматически очищается
