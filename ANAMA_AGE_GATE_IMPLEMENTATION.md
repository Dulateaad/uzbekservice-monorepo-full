# ✅ Реализация Age Gate и Parental Consent Flow для Anama

## 🎯 Что реализовано:

### 1. Age Gate Screen (`age_gate_screen.dart`) ✅
- Экран проверки возраста пользователя
- Выбор даты рождения через DatePicker
- Автоматический расчет возраста
- Определение категории: minor/adult/unknown
- Обработка "unknown age" как несовершеннолетний (требуется согласие)
- Переход к Parental Consent для несовершеннолетних
- Переход к регистрации для совершеннолетних

**Особенности:**
- Соответствует требованиям COPPA, GDPR и казахстанскому законодательству
- Трактует "unknown age" как детский режим (требует согласие)
- Минимальный возраст: 18 лет (совершеннолетие в РК)

---

### 2. Parental Consent Screen (`parental_consent_screen.dart`) ✅
- Экран для получения verifiable parental consent
- Методы подтверждения:
  - ✅ Email OTP (реализовано)
  - ⏳ eGov (планируется)
  - ⏳ KYC-light (планируется)
  - ⏳ Привязка карты (планируется)

**Функционал:**
- Ввод email и телефона родителя
- Отправка OTP на email
- Проверка OTP кода
- Отображение информации о согласии
- Чекбокс подтверждения согласия
- Сохранение согласия в Firestore

---

### 3. Parental Consent Service (`parental_consent_service.dart`) ✅
- Сервис для работы с родительскими согласиями
- Методы:
  - `sendOtpToEmail()` - отправка OTP на email
  - `verifyOtp()` - проверка OTP кода
  - `createParentalConsent()` - создание согласия в Firestore
  - `getActiveConsent()` - получение активного согласия
  - `revokeConsent()` - отзыв согласия

**Хранение данных:**
- Согласия хранятся в коллекции `parental_consents`
- OTP коды хранятся во временной коллекции `parental_consent_otps` с TTL

---

### 4. Модели данных (`parental_consent_model.dart`) ✅
- `ParentalConsent` - модель родительского согласия
- `AgeGateResult` - результат проверки возраста

**Поля ParentalConsent:**
- `id` - уникальный ID согласия
- `childUserId` - ID подростка
- `parentUserId` - ID родителя
- `parentEmail` - Email родителя
- `parentPhone` - Телефон родителя
- `consentMethod` - Метод подтверждения
- `isVerified` - Подтверждено ли согласие
- `createdAt` - Дата создания
- `verifiedAt` - Дата подтверждения
- `revokedAt` - Дата отзыва
- `isActive` - Активно ли согласие
- `metadata` - Дополнительные данные (IP, device info)

---

## 🔄 Flow процесса:

### Для несовершеннолетних:

1. **Регистрация** → `/auth/phone`
2. **Age Gate** → `/auth/age-gate`
   - Выбор даты рождения
   - Определение возраста < 18 лет
3. **Parental Consent** → `/auth/parental-consent`
   - Ввод данных родителя
   - Отправка OTP на email
   - Проверка OTP
   - Подтверждение согласия
4. **Создание профиля** → `/auth/create-profile`

### Для совершеннолетних:

1. **Регистрация** → `/auth/phone`
2. **Age Gate** → `/auth/age-gate`
   - Выбор даты рождения
   - Определение возраста ≥ 18 лет
3. **Создание профиля** → `/auth/create-profile` (без согласия)

## 📋 Маршруты добавлены:

```dart
// Age Gate
GoRoute(
  path: '/auth/age-gate',
  builder: (context, state) => const AgeGateScreen(),
),

// Parental Consent
GoRoute(
  path: '/auth/parental-consent',
  builder: (context, state) {
    final ageGateResult = state.extra as AgeGateResult?;
    return ParentalConsentScreen(ageGateResult: ageGateResult);
  },
),
```

## 📝 Использование:

### Для тестирования:

1. **Откройте приложение**
2. **Перейдите на** `/auth/age-gate`
3. **Выберите дату рождения** (например, 2010 год для несовершеннолетнего)
4. **Нажмите "Далее"**
5. **Если возраст < 18**, откроется экран Parental Consent
6. **Введите email родителя** и нажмите "Отправить код"
7. **Проверьте консоль** - там будет выведен OTP код (для тестирования)
8. **Введите OTP** и подтвердите согласие
